# 🩺 Kidney Disease Classification & Prediction
---

## 📌 Project Overview
The **Kidney Disease Classification & Prediction** system is a **Deep Learning powered web application** that helps in **early detection and accurate classification of kidney-related issues** using medical scan images.  

Our system significantly reduces **time and cost of medical consultations**, providing **faster, reliable, and AI-driven predictions** for users and healthcare professionals.  

---
---

## 🚀 Tech Stack
- 🌐 **Frontend:** HTML, CSS, Bootstrap  
- ⚙️ **Backend:** Flask  
- 🛢️ **Database:** SQLite3  
- 🤖 **Deep Learning:** CNN (Convolutional Neural Network) using TensorFlow & Keras

✨ Features

✔️ User-Friendly Web Interface with multiple pages:

🏠 Home Page – Introduction & details of the system

📤 Prediction Page – Upload kidney scan images

📊 Result Page – Get prediction with likelihood probability & confidence bar

📜 History Page – Check previous results

🔐 Signup/Login Page – Secure authentication for users

✔️ Deep Learning-based CNN model for kidney disease detection

✔️ Supports 4 classes of prediction:

🟤 Cyst

🟥 Tumor

🟪 Stone

🟢 Normal

✔️ AI Voice Assistant to read out the results

✔️ Downloadable Medical Report in text format

✔️ Early Detection & Cost Saving – Prevents unnecessary delays and provides accurate insights instantly

🎯 Purpose

💡 The main aim of this project is to assist in early diagnosis of kidney diseases by providing a fast, accurate, and cost-effective solution.
This tool helps both patients and doctors by reducing consultancy costs, saving time, and supporting better medical decision-making.
